## 学術的根拠

### Momentum（モメンタム）研究の歴史

#### 1. Hot Hand Theory（ホットハンド理論）
**Gilovich, Vallone, & Tversky (1985)**
- タイトル: "The Hot Hand in Basketball: On the Misperception of Random Sequences"
- 結論: 統計的には「ホットハンド」は幻想
- しかし: チームレベルの「流れ」は別の現象

#### 2. Psychological Momentum（心理的モメンタム）
**Iso-Ahola & Mobily (1980)**
- スポーツにおける心理的モメンタムの存在を提唱
- 連続得点が選手・チームの心理に影響

#### 3. Run Analysis in Basketball
**Arkes & Martinez (2011)**
- "Finally, Evidence for a Momentum Effect in the NBA"
- NBAデータから「流れ」の存在を統計的に証明
- **重要な発見**:
  - Run後の勝率は有意に高い
  - ホームチームの方がRunの恩恵を受けやすい

#### 4. Game Momentum Research
**Vallerand et al. (1988)**
- モメンタムが競技パフォーマンスに影響
- 「勢いに乗る」ことの科学的根拠

## Run-Counter Run分析

### Counter Runとは？

**定義**
- 相手のRunの直後（5分以内）に自チームがRunを作ること
- 「やり返し」の流れ

### Counter Runの発生率

```
【データ】（仮説ベース）

10-0 Run後、5分以内の相手の8-0以上Run発生率
→ 約25%

つまり：
- 4回に1回は「やり返される」
- Runを作っても安心できない
```

### Counter Runが起きやすい条件

1. **タイムアウト後**
   - コーチの指示で立て直し
   - 選手の集中力が戻る

2. **スター選手の覚醒**
   - やられたスターが奮起
   - 個人技で一気に得点

3. **ハーフタイム後**
   - 休憩で体力・集中力回復
   - 戦術の再調整

4. **ホームチームの反撃**
   - 観客の後押し
   - 「負けられない」プレッシャー

### Run-Counter Runパターン

#### パターンA: 一方的なRun
```
チームA: 10-0 Run
チームB: 反撃できず
→ チームAが大差で勝利
```

#### パターンB: やり返し合戦
```
チームA: 10-0 Run
チームB: 8-0 Counter Run
チームA: 6-0 Re-Run
→ 接戦のまま終盤へ
```

#### パターンC: 完全逆転
```
チームA: 10-0 Run（リード）
チームB: 15-0 Counter Run（大逆転）
→ チームBが勝利
```

### 勝敗を分けるのは？

**仮説**
1. **最後のRunを作ったチーム**が勝つ
2. **Counter Runを許さないチーム**が勝つ
3. **複数回Runを作れるチーム**が勝つ

**分析の焦点**
- Run後の「守備の引き締め」
- Counter Runされた時の「耐性」
- 第4Qで最後のRunを作る「終盤力」
