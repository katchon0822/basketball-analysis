# Bリーグ 夢のアリーナ効果 DID分析 計画書

作成日: 2026-03-30

---

## 分析の目的

「夢のアリーナ開業はクラブ収益に因果的な効果をもたらしたのか？」を差分の差分法（DID）で検証する。

単純な前後比較では「リーグ全体の成長トレンド」や「強いクラブだからこそアリーナを建てられた」という交絡を除去できない。DIDを使うことで、アリーナ開業による**純粋な効果**を推定する。

## 分析設計

### 処置群（Treatment）：夢のアリーナ開業クラブ

| クラブ | アリーナ名 | 開業時期 | 座席数 |
|--------|-----------|---------|--------|
| 千葉ジェッツ | LaLa arena TOKYO-BAY | 2024年5月 | 10,652席 |
| 長崎ヴェルカ | ハピネスアリーナ | 2024年10月 | 5,813席 |
| 群馬クレインサンダーズ | オープンハウスアリーナ太田 | 2023年4月 | 5,027席 |
| 佐賀バルーナーズ | SAGAアリーナ | 2023年5月 | 8,610席 |
| 琉球ゴールデンキングス | 沖縄サントリーアリーナ | 2021年4月 | 9,104席 |

### 対照群（Control）：アリーナ未開業クラブ
- B1残り19クラブ（同期間でアリーナ開業なし）

### 比較変数

| 変数 | 内容 |
|------|------|
| 入場料収入 | メインアウトカム。アリーナ容量の直接効果 |
| スポンサー収入 | 協賛価値向上の間接効果 |
| 営業収入（合計） | 総合的な収益効果 |

### DIDの式

```
Y = β0 + β1×Treated + β2×Post + β3×(Treated×Post) + ε

β3 = DID推定量（アリーナ開業の純効果）

Treated: 処置群=1、対照群=0
Post: 開業後=1、開業前=0
```

## リーグ全体トレンド（対照群の基準）

| シーズン | B1平均営業収入 | 前年比 |
|---------|-------------|-------|
| 2021-22 | 11.2億円 | - |
| 2022-23 | 14.2億円 | +26.8% |

| 2024-25 | 21.9億円 | +19.7% |

→ リーグ全体でも毎年20〜30%成長している。この**成長トレンドを除いた純効果**がDIDで求められる値。
