## 🚨 自動化の技術的課題

### 1. ボール検出の困難性
**問題点:**
- バスケットボールは小さい（画面の1-2%程度）
- 高速移動により、ブレや残像が発生
- YOLOv8の "sports ball" クラスでは検出率0%

**原因:**
- 一般的なスポーツボール検出モデルは、サッカーボールやテニスボールを想定
- バスケットボールの特徴（オレンジ色、黒い線）に特化したモデルが必要
- 低解像度動画（640x360）では特徴抽出が困難

### 2. シュート判定の複雑性
**必要な情報:**
- ボールの軌道（放物線）
- リムの位置
- ボールがリムを通過したか
- 成功 or 失敗

**実装の困難性:**
- リムの検出（標準YOLOには含まれない）
- カメラアングルの変化（座標変換が複雑）
- 遮蔽物（選手の体、手）による検出失敗

### 3. 選手識別の課題
**問題点:**
- 誰がシュートしたか判定困難
- ゼッケン番号の読み取りが必要（OCR + 低解像度で困難）
- 選手同士の重なりで個体追跡（トラッキング）が失敗

### 4. 座標マッピングの複雑性
**課題:**
- カメラ視点（斜め上から） → トップダウン座標への変換
- Homography変換が必要
- コートの4隅を手動で指定する必要あり
- カメラが動く場合、各フレームで再計算

## 💡 推奨アプローチ

### ✅ 推奨: 手動入力方式

**メリット:**
- ✅ 精度95%以上を保証
- ✅ すべてのシュート情報を正確に記録
- ✅ 選手名、シュートタイプ、結果を確実に取得
- ✅ 既に動作確認済み（YouTubeGameAnalyzer）

**デメリット:**
- ⏱️ 作業時間: 30-40分（19:42の動画に対して）

**作業フロー:**
```
1. 動画を再生しながら記録
2. CSVテンプレートに入力
   - shot_data_template.csv
   - box_score_template.csv
   - play_by_play_template.csv
3. analyze_youtube_game.py を実行
4. 自動で6種類のレポート生成
```

### ⚠️ 非推奨: 完全自動化

**理由:**
- ボール検出率: 0%
- シュート判定: 実装困難
- 選手識別: 精度不足
- 開発時間: 数週間〜数ヶ月（カスタムモデル訓練必要）

### 💡 今後の改善案（中長期）

#### 1. カスタムYOLOモデルの訓練
**手順:**
1. バスケットボール動画から1,000-5,000フレームを手動ラベリング
2. YOLOv8でファインチューニング
3. ボール、リム、選手を高精度で検出

**必要リソース:**
- データラベリング: 20-40時間
- GPU訓練環境: 数時間〜数日
- 専門知識: 物体検出、機械学習

#### 2. 半自動アプローチ
**コンセプト:**
- YOLOでシュートモーションを候補として検出
- 人間が確認・修正
- 作業時間を50%削減（40分 → 20分）

**実装ステップ:**
1. 人物のポーズ推定（手が上がっている = シュートの可能性）
2. 候補タイムスタンプを自動抽出
3. 人間が動画で確認して確定
