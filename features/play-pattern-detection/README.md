# プレー分解（ボール速度セグメンテーション + P&R候補検出）

選手トラッキングの断片化（5分間で397トラック、中央値3秒）を前提に、**信頼できるデータ（93%精度のボール追跡）を軸にした分析**として設計した。

## やっていること

1. **ボール速度の時系列化** — `ball_positions_sam3_300s.json`から速度・加速度を算出し、5フレーム移動平均で平滑化
2. **静止／動的の自動区切り** — 速度が閾値を一定時間下回る区間を「静止」、それ以外を「動的」として300秒を115区間に分割
3. **動的区間の分類（動き方パターン）** — 直線性と速度の周期性（自己相関）から「ドリブル候補」「パス候補」「不明」に分類
4. **P&Rスクリーン候補の検出** — 同チーム2トラックがボール付近で接近→分離する局面をルールベースで抽出（McQueen 2014の1段目に相当する候補生成）

## 結果（300秒、実データ）

| 指標 | 値 |
|---|---|
| ボール追跡カバレッジ | 93.1%（8,991フレーム中） |
| 検出セグメント | 115（静止57 / 動的58） |
| 動的区間の内訳 | ドリブル候補36 / パス候補9 / 不明13 |
| P&Rスクリーン候補 | 10件（うち分離確認7件） |
| 5人同時トラッキング率 | 62.5%（サンプリングフレーム中） |

可視化した詳細レポートは`outputs/play_patterns_300s.json`を参照。

## 実行

```bash
python analyze_play_patterns.py
```

## 正直な限界

- **速度はピクセル空間。** カメラのズーム・パン変化を補正しておらず、実速度（m/s）には未変換。静止判定の閾値（90px/s）は固定値
- **スペーシング指標（チームの凸包面積）は不採用。** 実装・計測したが、カメラのズーム変動により同一場面でも数十倍のノイズが乗り、信頼できる指標にならなかった
- **速度の外れ値にトラッキングノイズを含む。** 最大7,021px/sなど、SAM3がボールを一瞬見失い再検出した際のジャンプが混入している可能性がある
- **P&R候補は精度未検証。** ルールベースの一次候補生成であり、目視確認・適合率の計測は未実施
